# 💣 지뢰찾기

클래식 Windows 지뢰찾기의 입체 셀과 LED 카운터 디자인을 반영한 웹 지뢰찾기 게임입니다. Vanilla JavaScript로 구현했으며 별도 설치 없이 브라우저에서 실행할 수 있습니다.

## 게임 소개

닫힌 칸을 열어 숫자와 빈 공간을 확인하고, 지뢰가 의심되는 칸에는 깃발을 표시하세요. 지뢰가 없는 모든 칸을 열면 승리합니다.

- **초급:** 9 × 9, 지뢰 10개
- **중급:** 16 × 16, 지뢰 40개
- **고급:** 30 × 16, 지뢰 99개
- 첫 클릭한 칸과 주변 8칸은 안전합니다.
- 빈 칸을 열면 인접한 빈 칸과 숫자 칸을 자동으로 엽니다.
- 숫자 칸 주변의 깃발 수가 숫자와 일치할 때 좌우 동시 클릭으로 주변 칸을 열 수 있습니다.
- 타이머, 남은 지뢰 수, 승패 표시와 새 게임 버튼을 제공합니다.

## 어떻게 만들었나요

먼저 PRD 없이 게임을 만들어 기본 규칙과 동작을 확인했습니다. 이어서 PRD를 작성하고 구현 계획을 검토한 다음, PRD를 기준으로 게임 규칙을 보완했습니다. 보드 생성과 입력, 게임 상태 처리는 `script.js`, 화면 구조는 `index.html`, 클래식 디자인과 반응형 스타일은 `style.css`로 나누었습니다.

## freeform 버전과 비교했을 때

freeform 버전은 9 × 9 보드, 지뢰 10개, 타이머, 깃발과 승패 판정 등 기본 플레이에 초점을 맞췄습니다. PRD 버전에서는 첫 클릭한 칸뿐 아니라 주변 8칸도 안전하도록 규칙을 구체화했습니다. 최종 버전에는 초급·중급·고급 난이도 선택과 숫자 칸 좌우 동시 클릭도 추가했습니다.

## 실행 방법

### 로컬에서 실행

저장소를 내려받은 다음 `index.html`을 브라우저에서 여세요. 별도의 빌드나 패키지 설치는 필요하지 않습니다.

### GitHub Pages 배포

배포 주소: <https://djkwon-poly.github.io/26-w06-minesweeper/>

GitHub Pages 게시가 완료되면 위 주소에서 게임을 이용할 수 있습니다.

## 커스터마이징한 부분

- Windows 클래식 지뢰찾기를 떠올리는 회색 입체 프레임, 파란 타이틀 바, 빨간 LED 스타일 숫자 카운터를 적용했습니다.
- 난이도별 보드 크기와 지뢰 수를 선택할 수 있도록 했습니다.
- 좁은 화면에서는 큰 보드를 가로로 스크롤할 수 있습니다.
- 기존 지뢰찾기 규칙에 숫자 칸 좌우 동시 클릭(Chording)을 추가했습니다.

자세한 실습 절차와 PRD 템플릿은 [guide.md](./guide.md)를 참고하세요.
